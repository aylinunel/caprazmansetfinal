# Event selection — implementation note

This illustrative `media_practice` model selects up to `capacity` events from a supplied candidate list. Each event has explicit hypothetical `public_value` and `editorial_salience` scores in `[0, 1]`. At strength \(s\), the selector ranks events by \((1-s)\,public\_value+s\,editorial\_salience\), breaking ties by event ID, and fills the available slots. Strength is only an illustrative interpolation setting, not a calibrated behavioral parameter.

**Metric and reference.** The primary metric is the fraction of selected slots containing an event not selected by the strength-zero reference. The reference ranks by `public_value` alone and fills the same number of slots. Thus strength zero has metric 0 by construction. A positive metric describes a different selection, not an error, bias diagnosis, or necessarily worse coverage. State preserves other prior fields while updating the selected IDs, last metric, and number of selection steps.

**Necessary condition and scenarios.** The modeled divergence requires scarce coverage slots and competing rankings: the supplied positive example has one slot and an editorial-salience ranking opposed to the public-value ranking, so at strength 0.8 event C replaces reference event A. The boundary example provides enough slots for every candidate; removing scarcity means both policies select all events and the metric equals the strength-zero reference.

**Assumptions and limitations.** The candidate pool and both scores are supplied facts of a hypothetical scenario; the module does not infer them from news or language. Salience can represent legitimate audience, format, novelty, or operational needs, so the modeled choice is not inherently harmful. Actual news selection has many criteria and institutional constraints absent here. This compact mechanism is neither an NLP/media detector nor empirically or human validated; software tests establish only the specified synthetic behavior.
