# Selective statistics: illustrative implementation

This module simulates one narrow authored-presentation choice: whether a reported event count is divided by a supplied alternative denominator rather than by a documented, relevant comparison denominator. Given `event_count` $n$, relevant denominator $D_r$, selected denominator $D_s$, strength $s$, and supplied draw $u$, it uses $D_s$ exactly when $u < s$; otherwise it uses $D_r$. The primary metric is `100 × n / denominator_used`, in events per 100 members of the denominator used. The draw makes strength an explicit selection propensity rather than a rate offset; it is injected by the caller, and the evaluator uses no random source.

At strength zero the justified reference policy is to report the rate using the evidenced relevant denominator: $100n/D_r$. This is a task reference, not a guarantee of perfect rationality. Comparative evidence must explicitly attest both that the denominator exists and that it is relevant, with a nonempty description of its basis. Missing or negative evidence is an input error, not a zero score. The boundary scenario retains such evidence but sets $D_s = D_r$, removing the necessary denominator mismatch; its rate at strength .8 therefore equals the reference metric. The positive scenario uses $n=10$, $D_r=100$, $D_s=20$, and $u=.1$: the reference is 10 per 100 and the strength-.8 selection is 50 per 100.

Assumptions and scope: counts and denominators describe compatible populations, and the selected denominator is an explicit authored choice. The model records the resulting rate and choice; it does not decide whether either base is editorially justified, infer intent, classify text, or establish that a presentation is deceptive. Denominator evidence is trusted as structured input and cannot be independently verified. All values and the selection propensity are illustrative; the mechanism is synthetic and explicitly not empirically validated.
