# Functional fixedness implementation note

This is a hypothetical, synthetic process illustration, not an empirically validated psychology model or an NLP detector. A task supplies at least two feasible object uses, each with a unique ID, explicit utility in `[0, 1]`, and an explicit customary-use flag. The metric is utility regret: the highest supplied utility minus the selected use's utility, floored at zero, in task utility points.

At strength zero the reference rule selects the maximum-utility supplied use (input order breaks ties). When strength is positive and a customary use is supplied, the highest-utility customary use becomes the default. The best alternative is selected only when `alternative utility - customary utility > strength × customary utility`; otherwise the customary default is retained. This task-specific relative hurdle encodes resistance to reinterpreting an object in proportion to the utility of its customary role. If no customary use is supplied, the reference rule applies unchanged. The mechanism is active only when its choice differs from the exhaustive reference.

The positive scenario supplies a customary container use at utility `0.80` and an alternative tool use at `0.95`. At strength `0.8`, the hurdle is `0.64`, the customary use remains selected, and regret is `0.15`; at strength zero the alternative wins. The boundary scenario removes the customary-purpose condition by supplying only noncustomary uses; its strength-`0.8` metric and choice therefore equal the reference.

Assumptions: supplied uses are feasible, utilities meaningfully compare within the task, and customary labels are explicit and accurate. Strength and the hurdle equation are illustrative settings, not effect sizes. Limitations: the rule omits learning, affordance perception, temporal history, and individual differences; it cannot establish a person's internal experience. Choosing a customary use is not inherently an error—the metric is relative to the task utilities only. There is no empirical validation claim.
