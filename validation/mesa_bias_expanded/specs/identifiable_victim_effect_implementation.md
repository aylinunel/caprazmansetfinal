# Identifiable Victim Effect — implementation note

This is an explicitly hypothetical, synthetic process illustration, not an empirically validated psychological model or text detector. In a single decision, a fixed positive aid budget is split between exactly two options: one individual recipient and one anonymous comparator. Each has supplied positive expected-help-per-aid-unit effectiveness, and the output metric is aid units allocated to the focal (identified-recipient) option.

The strength-zero reference is an effectiveness-proportional allocation: `share_i = e_i / (e_i + e_a)`, where `e_i` and `e_a` are the respective supplied effectiveness values. If the focal person is individually identified **and** those effectiveness values are comparable within the documented numeric tolerance, the illustrative mechanism changes its weight to `e_i * (1 + 0.5 * strength)`, leaving the anonymous weight at `e_a`, then allocates the budget proportionally to those weights. The 0.5 coefficient is a transparent assumed parameter, not an empirical effect size. The output also carries cumulative allocations and decision count in state.

At strength 0.8 with equal effectiveness and a 12-unit budget, the rule allocates 7 units to the identified option versus the 6-unit reference. The contract boundary scenario removes individual identification while holding effectiveness equal, so the identity bonus is absent and allocation matches the reference. A separate test confirms that unequal effectiveness receives only the effectiveness-proportional reference allocation: a genuine effectiveness difference can justify unequal help and is not treated as an identity error.

The model assumes a two-option divisible budget and treats equal supplied effectiveness as comparability; it omits differences in urgency, recipient population size, uncertainty, constraints, and the possibility that personal detail communicates decision-relevant facts. Real-world help may appropriately prioritize a named recipient when effectiveness or need differs. No prevalence, causal claim, human validation, or detection accuracy is asserted.
