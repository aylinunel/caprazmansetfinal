# Cognitive dissonance: illustrative implementation

This plugin represents one explicitly supplied person/task state, not a population, classifier, or diagnosis. Inputs are normalized issue positions in `[0, 1]`: prior stated belief `b`, chosen action position `a`, new evidence position `e`, evidence weight `w`, commitment `c`, and choice freedom `v`. Missing evidence is an error.

The strength-zero reference policy is a linear evidence-weighted update, `b_ref = (1-w)b + we`. This is a declared comparison policy, not a claim of perfect rationality. The model's normalized discomfort proxy is `D = |b-a|cv`. For strength `s` in `[0,1]`, a hypothesized effort to reduce belief/action inconsistency shifts the reference position toward the freely chosen action: `b_next = b_ref + sD(a-b_ref)`. The primary metric is `b_next`, a position on the normalized 0–1 issue scale; `active` is true only when this formula changes the reference metric. The returned state records the reference belief, next belief, discrepancy, discomfort proxy, shift, and number of evaluated rounds.

The positive example supplies a committed prior position that conflicts with a freely chosen action, plus contrary evidence; at strength 0.8 the modeled position is pulled toward the action relative to the reference. The boundary example sets choice freedom to zero; removing that necessary condition eliminates the pull and exactly reproduces the reference metric. A commitment of zero likewise makes the modeled pull zero. The reference at strength zero is always the stated weighted-evidence rule.

All coefficients and the discomfort proxy are illustrative assumptions, not measured effect sizes. Cognitive dissonance is a psychological state, and resolving it through honest belief revision is not itself biased reasoning. This narrow model represents only one possible action-alignment resolution pathway; it omits alternatives such as behavior change, tolerating discomfort, and context-sensitive evidence evaluation. It is explicitly hypothetical and not empirically validated; tests verify software behavior, not psychological validity.
