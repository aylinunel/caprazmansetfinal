# Labeling mechanism implementation note

**Process.** For the same actor in multiple outlets, each supplied epithet/title has an explicit hypothetical legitimacy preset \(p_i\), and the scenario supplies a shared factual reference \(b\). The modeled outlet impression is \(r_i=b+s(p_i-b)\), where \(s\in[0,1]\) is a user-settable intervention strength. The primary metric is \(\max_i(r_i)-\min_i(r_i)\), measured in legitimacy points on a 0–1 scale. At strength zero the reference policy gives every outlet the shared evidence baseline and therefore spread 0; the modeled metric is \(s(\max_i p_i-\min_i p_i)\) when labels differ. The mechanism is active only when differing labels at positive strength produce a nonzero spread.

**Necessary condition and scenarios.** The task requires at least two outlet observations explicitly referring to the same actor, plus different labels (epithets/titles). Label semantics are never inferred from strings: each label's preset must be supplied. The positive scenario provides “reform leader” (0.9) versus “power broker” (0.1) around a common baseline of 0.5; at strength 0.8 the metric is 0.64. The boundary scenario uses “mayor” in both outlets with the same preset, removing label divergence; its metric equals the strength-zero reference, 0.0.

**Assumptions and limitations.** Preset scores and linear adoption are illustrative assumptions, not published effect sizes. This models a supplied authored media practice and a hypothetical reader impression, not a natural-language detector, motive attribution, population claim, or empirically validated psychological effect. It omits outlet context, audience differences, label familiarity, and other causes of legitimacy judgments; identical wording may still carry different meanings in real contexts. The concept specification provides no narrower annotation boundary, so this implementation confines itself to explicit structured same-actor cross-outlet label contrasts and does not make empirical claims.
