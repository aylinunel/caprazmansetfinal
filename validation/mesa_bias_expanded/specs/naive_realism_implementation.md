# Naive Realism — illustrative implementation

This synthetic process model updates a hypothetical probability estimate. With own estimate `p`, evidence target `t`, and evidence weight `w`, its explicit strength-zero reference is `p_ref = p + w(t-p)`. A mechanism effect is enabled only when (1) the supplied dissenting estimate differs from `p` by at least 0.10, (2) the evidence target points in the same direction as that dissent, (3) the agent is explicitly stipulated to regard its own view as neutral, and (4) positive defect-attribution strength `a` is supplied. When all conditions hold, evidence weight becomes `w_eff = w(1-strength*a)` and the reported metric is `p_next = p + w_eff(t-p)`; otherwise the reference update is used. The primary metric is a probability on `[0,1]`.

The positive scenario has counterevidence aligned with a dissenting view plus explicit neutral-self framing and defect attribution, so strength 0.8 discounts the counterevidence. The boundary scenario presents a well-supported fact consistent with the agent's estimate and no dissenting estimate; it must match the reference regardless of strength. The model takes all social attributions as explicit hypothetical inputs and does not infer them from language.

The linear evidence-integration rule, 0.10 disagreement threshold, and strength/attribution coefficients are illustrative assumptions, not measured psychological parameters. This is not an NLP detector, diagnosis, population claim, or empirically validated account. It cannot determine whether dissenters are actually biased or whether discounting a particular argument is justified; the update ignores evidence uncertainty, source quality, context, and richer social learning. A test pass establishes software behavior only, not empirical validity.
