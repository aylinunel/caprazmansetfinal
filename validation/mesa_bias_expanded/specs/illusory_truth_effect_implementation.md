# Illusory Truth Effect — illustrative implementation

This plugin models the supplied boundary: repeated exposure can raise the modeled credibility of a claim when the current encounter adds no new independent evidence; repetition accompanied by new independent evidence is scored by the evidence reference rule instead. It is a synthetic process illustration, not an NLP detector or an empirically validated account of people.

For each `claim_id`, the state stores its count of exposures, cumulative evidence log-odds, and evidence IDs already consumed. The strength-zero reference is explicit: start at neutral log-odds 0 and add each unique supplied `log_likelihood_ratio`, then return `sigmoid(evidence_log_odds)`. A duplicate evidence ID is not counted again. For strength `s > 0`, an exposed claim with at least one prior exposure and no new evidence in that step receives the task-specific familiarity term `0.55 × s × ln(1 + prior_exposure_count)` added to its evidence logit. The reported primary measure is the resulting bounded 0–1 modeled credibility index, not a calibrated probability. The coefficient is an illustrative assumption, not a published effect size.

The positive sequence repeats one claim with an explicit empty evidence list and therefore separates at strength 0.8 from the evidence-only reference. The boundary sequence supplies a distinct independent evidence ID at every exposure; the familiarity term is not applied, so its metric matches strength zero at each step. Missing `evidence` is rejected rather than interpreted as no evidence; callers must pass `[]` explicitly. Inputs require a non-empty claim ID, a Boolean exposure flag, and evidence entries with non-empty IDs and finite log-likelihood ratios in [-50, 50].

Limitations: callers must establish that evidence IDs really represent independent evidence and provide meaningful likelihood ratios. The model assumes a neutral prior, no forgetting, and no source-quality or comprehension effects; familiarity can have benign or neutral explanations in real contexts. No human validation, detection accuracy, or empirical effect-size claim is made.
