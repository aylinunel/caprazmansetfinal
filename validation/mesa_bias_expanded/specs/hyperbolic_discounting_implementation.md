# Hyperbolic discounting implementation note

This plugin models hypothetical choices between a smaller-sooner reward `(A_s, d_s)` and a larger-later reward `(A_l, d_l)`. It requires positive reward amounts, nonnegative delays, `A_l > A_s`, and `d_l >= d_s`. Every trial validates these phase-specific requirements; missing or impossible evidence raises `ValueError` rather than being treated as a no-effect observation.

For amount `A` delayed by `d` days, the strength-zero reference value is exponential, `V_E = A exp(-0.15 d)`. The illustrative hyperbolic value is `V_H = A / (1 + 0.20 s d)`, where `s` is the generic intervention strength. Intervention choice compares `V_s = (1-s)V_E + sV_H` for each option. A strict larger-later value advantage selects that option; ties select smaller-sooner. Thus strength zero is an explicit exponential reference, not a claim of perfect rationality. The primary metric is the cumulative **count of larger-later choices** over the chronological trials, and state retains the full choice sequence, count, number of choice reversals, and trial count. `active` indicates whether the selected option differs from the exponential reference on that trial.

The positive scenario presents the 18-now/20-later options first at delays 30/31 days and then at 0/1 days. At strength 0.8, hyperbolic interpolation selects larger-later at the distant horizon and smaller-sooner near the present; the exponential reference selects smaller-sooner at both horizons. This is a simple reversal pattern consistent with decreasing impatience. The boundary scenario gives both options the same delay on each of two trials. That removes the differential-delay condition needed for intertemporal discounting to alter their rank: both rules select the larger amount, so final metrics match.

All rates are hypothetical, user-settable assumptions, not empirically estimated effect sizes. The scenarios are constructed demonstrations, not evidence about prevalence, individual psychology, or out-of-sample accuracy. A reversal does not establish an exact hyperbolic function, and the account overlaps with present bias. The plugin is not an NLP detector, diagnosis, or inference about real people's motives or preferences.
