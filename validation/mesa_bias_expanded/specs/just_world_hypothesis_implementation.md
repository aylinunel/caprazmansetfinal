# Just-world Hypothesis — illustrative implementation

This plugin models a structured attribution choice, not natural-language detection. Given a supplied outcome (adverse or beneficial) and candidate explanations, the strength-zero reference selects the candidate with the highest supplied `evidence_support` in `[0, 1]`, breaking ties by candidate order. If there is no supported action-specific consequence claim, each candidate explicitly marked `says_deserved` receives a strength-scaled illustrative prior of `0.6 × strength`; the choice maximizes `evidence_support + prior`. The selected option is the process outcome, so this is a task-specific competing-choice model rather than a generic metric penalty.

**Task and units.** Choose among supplied attribution options. The primary metric is `selected_desert_attribution`, a binary indicator (1 if the selected explanation says the outcome was deserved, else 0). State carries the number of decisions, number of selected desert attributions, and the last selected option. `active` is true only when the selected option differs from the evidence-only reference.

**Necessary condition and boundary.** The outcome/desert prior is eligible only when `action_consequence_supported` is false. If task evidence supports a consequence claim about a specific action, the prior is fully suppressed and the reference policy is used, regardless of strength; that case is not labeled as just-world reasoning.

**Illustrative scenarios.** In the positive case, structural-misfortune support is 0.4 and victim-desert support is 0.1. At strength 0.8 the latter scores 0.58 (`0.1 + 0.6 × 0.8`) and beats 0.4, changing the metric from 0 to 1. In the boundary case, a supported specific-action explanation has support 0.8 and the desert explanation 0.1; both strength zero and 0.8 select the supported explanation, metric 0.

**Assumptions and limitations.** Candidate descriptions, support ratings, and whether action-specific evidence is supported are explicit scenario facts, not inferred by this module. The prior coefficient is a transparent illustrative choice, not a published effect size. Real judgments can have benign explanations, including evidence-based causal reasoning, cultural norms, or compassion; the model does not adjudicate morality, represent population prevalence, diagnose people, or claim empirical validity. It is synthetic-only and not empirically validated.
