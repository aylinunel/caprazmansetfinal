# Illusion of Validity: illustrative implementation

This synthetic module models a binary prediction from signed cues (`-1` or `+1`). Its primary metric is reported confidence in the selected label, on a 0–1 probability scale. The strength-zero reference combines the supplied base rate with the cues as if conditionally independent, using the supplied `claimed_accuracy` as each cue's reliability: `L = log(base_rate/(1-base_rate)) + sum(cue_signs)*log(claimed_accuracy/(1-claimed_accuracy))`; the reference confidence is `sigmoid(abs(L))`, and the sign of `L` selects the label (ties select `+1`).

At positive strength, the illustrative concept process adds `strength * coherence * max(0, claimed_accuracy - validated_accuracy) * (1 - reference_confidence)` only if all cues agree and validated accuracy is below claimed accuracy. Coherence is the share of cues favoring the majority sign. Thus the modeled effect requires both a coherent impression and evidence that the inference's validity is overclaimed; confidence alone does not trigger it. The state reports the prediction, confidence, cue count, and coherence, preserving unrelated prior state fields. The process is stateless across rounds because the specified concept does not require a temporal claim.

The positive scenario uses three unanimous positive cues (claimed accuracy .8, validated accuracy .55, neutral prior), so reported confidence increases over the reference. The boundary scenario changes one cue to negative; absent unanimity, the metric equals the reference at strength .8. A second tested boundary keeps unanimity but removes overclaiming by setting validated accuracy above the claim.

Assumptions are deliberately narrow: cue accuracies are treated as common across cues; the reference's conditional-independence rule may be wrong; validation is provided as structured evidence rather than inferred; and the confidence-inflation relationship is stipulated, not fitted. The module is an executable illustration, not empirical validation, a diagnosis, population claim, or language detector. A real coherent pattern may be reliable, and correlated cues may be useful in ways this small model does not represent.
