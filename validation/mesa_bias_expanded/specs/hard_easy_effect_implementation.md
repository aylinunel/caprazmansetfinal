# Hard-easy effect implementation

This is a synthetic sequential task model, not a detector or fitted psychology. Each task supplies an explicit difficulty (`hard`/`easy`), reference-policy confidence `p`, and binary outcome `y`. The strength-zero reference reports `p` unchanged. Once the sequence contains both difficulty levels, the model reports `p + 0.25s(1-p)` for a hard task or `p - 0.25sp` for an easy task, where `s` is the intervention strength in `[0,1]`. These bounded, direction-specific shifts express the stipulated high-hard/low-easy confidence pattern; the coefficient is illustrative, not an effect-size claim.

The primary metric is the mean signed calibration residual (`reported confidence - outcome`) on hard tasks minus the corresponding mean on easy tasks, in probability points. It is zero until both levels are present, because a single difficulty group cannot establish the specified cross-difficulty pattern. The positive scenario observes a hard failed task followed by an easy successful task; the boundary scenario contains only hard tasks and must match strength zero. Inputs, including outcomes, are explicit; missing or impossible task evidence raises `ValueError` rather than being treated as a zero observation.

Limitations: task labels, reference confidences, and outcomes are assumed known and externally supplied; observations may be too few or imbalanced for a stable descriptive contrast; the sequence gate is a modeling choice. This illustrative implementation is explicitly hypothetical and has not been empirically validated. Tests establish code behavior only, not psychological validity.
