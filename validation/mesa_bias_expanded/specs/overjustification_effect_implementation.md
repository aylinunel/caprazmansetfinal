# Overjustification effect — illustrative implementation

This module models one narrow motivational process, not a classifier, diagnosis, or claim about a population. The task is a fixed optional-activity probe: record an explicit prior-interest value and voluntary baseline minutes, expose the activity to one or more explicit contingent rewards, then simulate a later unrewarded probe. Its primary metric is predicted voluntary minutes in that probe.

For reward saliences \(s_i\in[0,1]\), the task's cumulative dose is \(D=1-\prod_i(1-s_i)\). The post-reward prediction is \(M=B(1-\lambda I D)\), where \(B\) is the recorded baseline voluntary time, \(I\) the explicit pre-reward intrinsic-interest input, and \(\lambda\in[0,1]\) the uncalibrated intervention setting. The unchanged reference uses \(\lambda=0\); it preserves baseline minutes and is not asserted to be an optimal or universally rational policy. The simulated decline is enabled only in the post-reward phase and requires both a preceding baseline and nonzero contingent-reward exposure. A zero-interest baseline therefore removes a necessary condition and yields the unchanged metric even with reward exposure.

`positive` has three chronological phases (interested baseline, salient contingent reward, unrewarded probe) and predicts a decrease at strength 0.8 relative to 0. `boundary` retains the same reward sequence but explicitly sets prior interest to zero, predicting equality. The implementation validates phase-appropriate contingency, salience, chronological state, and stable baseline inputs. It performs no inference about hidden motives.

The multiplicative exposure and decline equation is a compact illustrative assumption, not an empirical effect size. It omits reward type, autonomy, attribution, task meaning, social context, and many individual differences; real changes in activity may have benign alternative causes. The process is deliberately hypothetical, and software-contract tests do not establish empirical validity.
