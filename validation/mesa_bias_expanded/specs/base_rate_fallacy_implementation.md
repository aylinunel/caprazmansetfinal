# Base Rate Fallacy: implementation note

This illustrative process model estimates the probability of a target hypothesis given an explicitly supplied population prevalence `p` and case-specific evidence likelihood ratio `LR`. Its primary metric is the resulting hypothetical target probability (unitless, in `[0, 1]`). The strength-zero reference is ordinary odds integration: `logit(q₀) = logit(p) + log(LR)`, equivalent to Bayes' rule for the supplied inputs.

The modeled neglect process gives diagnostic case evidence excess weight relative to prior odds: `logit(qₛ) = logit(p) + (1 + s) × log(LR)`, where `s ∈ [0, 1]` is an illustrative intervention setting, not an empirical effect size. At `s = 0` it reproduces the reference; at positive strength it overweights the supplied case-specific signal. This direction is visible in the positive scenario (`p = 0.02`, `LR = 9`, strength `.8`). The boundary scenario uses `LR = 1`: there is no diagnostic case-specific information to favor over the available base rate, so the biased and reference metrics are equal at strength `.8`.

The module requires finite `0 < p < 1` and finite `LR > 0`; missing or impossible evidence raises `ValueError`. It carries a step count and the last biased/reference probabilities in its next state while preserving other state fields. Inputs are explicit hypothetical structured facts, not inferred from prose. This is a narrow assumed process, not exhaustive psychology, a detector, an empirical validation, or a claim about real decisions. The likelihood ratio is treated as known; evidence quality, uncertainty, relevance, costs, and rational reasons to prioritize strong evidence are outside scope. The strength coefficient and scenarios are synthetic assumptions only.
