# Extrinsic Incentive Bias — implementation note

This module simulates a narrow, hypothetical self–other attribution asymmetry. Each target has supplied, normalized reward and intrinsic-motive evidence. The reference estimate for a target is its reward share, `R / (R + I)`. At strength `s`, the other's reward cue is weighted by `1 + s(1 - D)`, where `D` is supplied other-motive documentation completeness; the reported metric is `R_other[1 + s(1-D)] / (R_other[1 + s(1-D)] + I_other)`. The self estimate remains the proportional reference share. Inputs represent structured scenario evidence, not facts inferred from text or hidden motive states. The metric is the proportion of the other's attributed motivation assigned to external reward.

At strength zero, the reference rule attributes reward in proportion to the explicit reward and intrinsic signals for both targets. The differential process is active only when the other has a positive reward signal, documentation is incomplete, and strength is nonzero. Thus the required boundary scenario fully documents the other's motives (`D = 1`) and exactly recovers the reference metric; a zero other-reward signal also cannot induce an extrinsic attribution increase. The positive scenario supplies equal self/other reward and intrinsic evidence with no other-motive documentation: at strength 0.8, the attributed other reward share rises from 0.4 to `6/11` (about 0.5455).

The model assumes signals and documentation are meaningful values on [0, 1], and that underdocumentation permits an observer to overweight another person's salient reward cue. Coefficients are illustrative user-settable assumptions, not empirical effect sizes. Incomplete documentation does not prove an extrinsic motive; reward and intrinsic reasons can coexist, and observed rewards may be incidental. This is a compact synthetic process illustration, not an empirically validated psychological model, population claim, diagnostic, or natural-language detector.
