# Levels of Processing: implementation note

This is a compact hypothetical memory-task mechanism, not a judgment-error model, detector, diagnosis, or fitted account of human memory. The task is to encode a named item over one or more chronological study events and then probe that same item. Inputs explicitly specify study exposure and processing depth; no text or hidden mental state is inferred.

For a study event with exposure `e > 0`, explicit semantic-processing depth `d ∈ [0,1]`, and intervention strength `s ∈ [0,1]`, the exposure-only reference trace increases by `e`. The modeled trace increases by `e × (1 + 1.5 × s × d)`. The coefficient is an illustrative assumption. A probe reports the deterministic task metric `sigmoid(cumulative_trace − 1.5)`, a modeled recall probability on [0,1], not an empirical probability estimate. The strength-zero reference is the same task with exposure retained and elaboration contribution removed. Multiple study events accumulate separately in item state; a probe before any valid study is rejected.

The positive scenario holds exposure constant, supplies positive processing depth, and compares the final probe at strength .8 with strength zero. The boundary scenario supplies exposure but sets processing depth to zero, removing the necessary condition for the modeled elaboration increment; its final recall metric therefore equals the strength-zero reference. These are short chronological study/probe contexts, not extra simulated time steps.

Only `action` and `item_id` are universal required metadata inputs. `exposure_units` and `processing_depth` are required and validated for study events specifically; probes instead require a prior studied item in state. The model preserves item-level exposure, reference trace, modeled trace, elaboration dose, and event history.

Limitations: coefficients, the retrieval criterion, and logistic readout are user-set assumptions, not published effect sizes or calibrated parameters. Strength represents an intervention setting, not prevalence or confidence. Attention, distinctiveness, prior knowledge, forgetting, interference, retrieval cues, and individual variation are omitted. Meaningful elaboration can be a beneficial memory process; no harm or irrationality is implied. Passing tests or runner checks establish only executable-contract consistency, not empirical validity.
