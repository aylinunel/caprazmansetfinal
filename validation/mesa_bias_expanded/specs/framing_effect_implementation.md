# Framing Effect — illustrative implementation

**Process and task.** This module compares a single selected option among two structured choice alternatives under a paired gain/loss presentation. Each option is a probability distribution over canonical outcome points. It treats the supplied presentations as equivalent only when their option IDs and each probability/outcome distribution match (within a tiny numeric tolerance). It does not parse prose.

For option `i`, the strength-zero reference score is its expected outcome, `EVᵢ = Σ pⱼvⱼ`; the reference chooses the highest EV, breaking ties by listed order. If and only if the paired distributions are equivalent, the selected presentation uses `scoreᵢ = EVᵢ + s × c × sign(frame) × Varᵢ`, where `s ∈ [0,1]`, `c = 0.002` inverse outcome-points, `sign(gain) = −1`, and `sign(loss) = +1`. Thus a gain frame penalizes risk while a loss frame rewards risk in this deliberately simplified model. The primary metric is the selected option's zero-based list index (numeric, dimensionless); state additionally records the option name, reference choice, selected frame, and eligibility.

**Necessary condition and boundary.** Both gain and loss versions must be present, and all named options must have matching canonical outcome distributions. If they differ, this is treated as potentially different information rather than framing: the module ignores strength and uses the expected-value reference choice. Missing/malformed evidence raises `ValueError`, rather than silently producing a zero metric.

**Scenarios.** The positive scenario has a certain 90-point option and a 50/50 lottery yielding 0 or 200 points. The reference chooses the lottery (EV 100); at strength 0.8 under gain wording, the illustrative variance premium changes the lottery score to 84, so the certain option is chosen. The boundary scenario changes the lottery's possible outcome in the loss presentation from 200 to 180; because the numerical facts are no longer equivalent, strength 0.8 gives the same reference choice as strength zero.

**Assumptions and limitations.** The variance coefficient and frame signs are user-set illustrative assumptions, not published effect sizes or estimates. Outcomes must share an interpretable point scale, and the coefficient's result depends on that scale. This compact paired-choice process is neither empirically validated nor a population model, clinical inference, or natural-language detector. Numeric identity cannot guarantee substantive equivalence or capture real-world framing, choices, ambiguity, or benign reasons for preferring risk. Passing tests only validates software behavior, not psychology.
