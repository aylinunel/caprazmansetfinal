# Belief perseverance implementation note

This is an explicitly hypothetical, synthetic process model—not an empirically validated effect or a detector. Each chronological event updates an evidence ledger. The task observable is the agent's probability for a claim: `logistic(prior_log_odds + signed weights of non-discredited evidence + residual_log_odds)`. Evidence weights are illustrative log-odds units, bounded to 0–20. The metric is a finite probability in [0, 1].

The strength-zero reference policy recalculates from the supplied prior and all evidence that has not been discredited. A correction must cite a previously supplied evidence item. When that item was positive support, the perseverance subtype adds `strength × cited weight` back to the reference log-odds; the separately labeled backfire subtype adds `strength × 2 × cited weight`. The larger backfire coefficient is a transparent synthetic assumption, not a finding. Perseverance therefore does not itself imply backfire. Correcting negative or neutral evidence leaves no residual and is the boundary case.

The positive scenario supplies supporting evidence and then discredits it; at strength 0.8 the retained contribution increases the claim probability over the reference. The boundary scenario discredits a negative item, so the necessary condition—discredited supporting evidence—is absent and the primary metric equals strength zero. Sequences are carried through returned state; no history is inferred from a single snapshot.

Inputs require a prior probability, a typed evidence/correction event, bounded numeric weights, unique evidence IDs, and an existing correction target. Missing or impossible evidence raises `ValueError`. Assumptions are user-settable process choices, not calibrated coefficients. This compact model omits source credibility, language interpretation, motives, real-world measurement, and benign explanations for a person's response; observed real-world persistence cannot be inferred from it. Tests establish only software behavior and stipulated equations, not psychological validity.
