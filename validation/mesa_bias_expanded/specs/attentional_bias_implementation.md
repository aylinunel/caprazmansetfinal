# Attentional Bias — implementation note

This is a hypothetical, synthetic-only attention-allocation process model, not an empirical account, classifier, or detector. Given a display of at least two explicitly described items, it assigns one attention slot using `score = (1 − strength) × relevance + strength × capture`. The item with the largest score is selected (input order resolves ties). The primary metric is the selected item's supplied task relevance, a unitless value on the input's 0–1 scale. The model records the attended item and relevance in state; it does not simulate a later judgment or reweight evidence after attention.

At strength zero, the stated reference policy selects the item with the greatest task relevance. A positive case contrasts relevance 1/capture 0 with relevance 0.4/capture 1: at strength 0.8, the capture-weighted selection attends the latter and the metric falls from 1 to 0.4. The boundary case gives both items equal capture; because capture then cannot alter their relevance ranking, the strength-0.8 primary metric equals the strength-zero reference. The necessary modeled condition is a capture difference strong enough to change selection away from the reference item; selection remains tied to the supplied structured values.

The inputs' relevance and capture values are assumed to be commensurate, meaningful 0–1 quantities and are not inferred from media or people. Strength and the linear blend are illustrative user-set assumptions, not effect sizes or calibrated psychology. One-slot selection omits divided attention, task context, changing salience, memory, and individual differences. A salient item may be useful when it is relevant, so capture-driven attention is not inherently harmful. The code and scenarios are explicitly unvalidated; passing tests establishes software behavior only, not psychological validity.
