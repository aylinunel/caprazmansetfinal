# Responsibility framing: implementation note

This illustrative **media-practice choice model** selects between a headline that leads with an available responsibility claim and one that leads with process status. The primary observable is `headline_attribution_choice`: `1.0` for the attribution lead and `0.0` for the process lead.

Let `a` be attribution salience, `e` explicit support for the responsibility claim, `p` process-frame salience, `c` indicate a completed process, `q` indicate that a responsibility claim is available, and `s` be strength. The reference rule assigns attribution score `a × e` and selects attribution only when `q` is true and that score is strictly greater than `p` (ties select process). The simulated framing pressure adds `s × (1−c) × q × a × (1−e)`. The choice is attribution only when the combined score strictly exceeds `p` and `q` is true. Thus the effect requires an incomplete process and an available responsibility claim, and it is reduced as explicit support rises. This is not a natural-language detector.

The positive scenario has a claim available, an incomplete process, weak support, and sufficient attribution salience for the pressure term to flip the choice at strength 0.8. The boundary scenario changes only process completion; the pressure term is then zero, so the primary metric equals the strength-zero reference. A fully supported available claim can also win under the reference rule, so attribution is not inherently treated as erroneous. The model assumes supplied salience/support values are meaningful for this synthetic task; it omits richer editorial choices, legal context, and audience interpretation. Its formula is stipulated, has no fitted coefficients, and has not been empirically validated.
