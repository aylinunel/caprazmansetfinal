# Peak-end Rule implementation

This compact process model takes chronologically supplied satisfaction scores on a 0–10 scale. Before a marked ending, its task metric is the arithmetic mean of observed moments. On the context that explicitly marks `episode_end=True`, it computes `mean = average(all scores)`, `peak = max(all scores)`, `peak_end = (peak + final score) / 2`, and `rating = (1 - 0.6 × strength) × mean + (0.6 × strength) × peak_end`. The 0.6 mixture coefficient is an illustrative assumption, not a measured effect size. State retains the score history and whether the episode ended; the runner supplies only the sequence's contexts, not hidden chronology.

The metric is an illustrative episode satisfaction rating in satisfaction points. Strength zero is the explicit mean-of-observed-moments reference policy, not a claim of perfect judgment. The mechanism is active only at a marked episode end, with nonzero strength and a peak/end summary that changes the arithmetic-mean rating. A single moment is rejected as insufficient to distinguish a peak/end summary from the ordinary mean.

The positive scenario supplies four chronological moments (2, 4, 10, 8) and marks the final moment as the episode end; the peak/end summary exceeds the mean, so the intervention raises the final rating. The boundary scenario supplies the same observations but never marks an episode end. This removes the required explicit completion evidence, so no retrospective peak-end evaluation is made and its final running-mean metric equals strength zero. Merely supplying a final score without marking completion is deliberately insufficient, consistent with the annotation boundary that an ending mention alone does not establish disproportionate retrospective weighting.

This is synthetic-only and not empirically validated. Scores and the endpoint marker are structured hypothetical inputs, not inferred from language or used to diagnose people. The model defines peak as maximum satisfaction, ignores duration, affect intensity, recall dynamics, context, and alternative peak definitions, and cannot establish that real retrospective judgments follow this process. Strength is an uncalibrated intervention setting; passing software checks is not evidence of psychological validity.
