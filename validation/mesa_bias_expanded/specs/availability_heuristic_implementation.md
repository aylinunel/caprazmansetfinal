# Availability Heuristic — illustrative implementation

**Process and equation.** The task is to judge the probability of an event from a finite set of observed cases. For `N` cases, the reference frequency is `p_evidence = event_count / N`. Each case supplies an explicit `recall_ease` weight in `[0, 1]`; the availability estimate is `p_available = sum(recall_ease for event cases) / sum(recall_ease for all cases)`. The returned primary metric is `p_judgment = (1 - strength) * p_evidence + strength * p_available`.

**Task, units, and baseline.** The metric is a subjective event-probability judgment, measured on a 0–1 scale. Strength zero explicitly returns the observed sample frequency; this reference rule is not claimed to be universally optimal or perfectly rational. Strength is an illustrative intervention setting, not a calibrated psychological effect or prevalence estimate.

**Necessary condition and scenarios.** The mechanism requires observed event/non-event evidence and a nonzero sum of explicit recall-accessibility weights. Its diagnostic condition is that accessibility-weighted frequency differs from observed frequency: merely having recent or accessible examples is not enough. The positive scenario has the event case unusually accessible and therefore increases the probability judgment at strength 0.8. The boundary scenario gives event and non-event cases equal accessibility, so weighted frequency equals observed frequency and the metric matches the strength-zero reference.

**Assumptions and limitations.** Cases are equally weighted observations, and supplied recall-ease values are hypothetical accessibility proxies rather than inferred mental states. The linear blend and coefficients are illustrative assumptions only. Accessibility can be informative in real contexts; the model does not imply that a helpful heuristic is inherently erroneous. It has no NLP detector, does not infer recency or vividness, and has not been empirically validated; passing software tests establishes only that the specified synthetic process behaves as coded.
