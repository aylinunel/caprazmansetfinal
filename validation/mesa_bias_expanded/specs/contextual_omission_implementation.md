# Contextual omission implementation note

This illustrative, structured-facts model takes a presented baseline contrast and signed comparison adjustments for facts in an available full text. Only a fact explicitly marked accessible, relevant, and counter-evidence qualifies. Let `full = base + sum(all qualifying adjustments)` and `presented = base + sum(qualifying adjustments shown)`. The reported reader contrast is `full - strength * (full - presented)`. Strength zero is the explicit reference policy: use the complete full-text contrast. Strength one follows the contrast represented by the presented facts. The metric is a synthetic percentage-point contrast between compared groups; it is not a confidence or bias score.

A candidate requires available full text and supplied accessible, relevant context facts. A modeled omission effect additionally requires qualifying relevant counter-evidence that is not included and changes the contrast. The positive scenario omits a signed denominator adjustment of -8 from a baseline contrast of 12: the full-text reference is 4 and the contrast at strength .8 is 10.4. The boundary scenario supplies relevant accessible context but no counter-evidence, so the contrast remains 12 and matches the strength-zero reference.

These are hypothetical process assumptions, not empirically validated effects. Inputs encode evidence status and adjustments; the module does not inspect prose, infer truth, relevance, or author intent, or distinguish deliberate omission from benign compression. It covers a simple additive contrast only, with no uncertainty, interactions, or population-level interpretation. A shifted comparison by itself does not establish error or harm.
