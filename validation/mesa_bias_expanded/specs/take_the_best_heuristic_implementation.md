# Take-the-best heuristic: illustrative implementation

**Process.** The task supplies a finite option set, a prioritized list of cue ratings for every option, a positive minimum rating range, task scores, and (for positive-strength stochastic choice) the runner's uniform draw. The strength-zero reference sums ratings equally across all cues and selects the maximum, breaking ties by listed option order. At positive strength, when the first cue whose max-minus-min rating reaches the threshold exists, the policy uses that cue's highest-rated option with probability `strength`; the supplied matched uniform draw implements that choice. Otherwise it uses the aggregate reference. The primary metric is the selected option's supplied task score in arbitrary task-score points, and `active` is true only when the TTB branch changes the reference choice. State stores the full choice history and latest choice/policy/cue.

**Task and scenarios.** The positive fixture gives the priority cue a qualifying A-over-B difference while the secondary cue makes B win the aggregate reference; A's stipulated task score is higher. It therefore illustrates a case in which the heuristic can be useful, not a universal advantage. The boundary fixture removes discrimination on every cue (all ratings tied), so the necessary first-discriminating-cue condition is absent and both policies select the same reference option and score.

**Scope and limitations.** Ratings, cue order, threshold, and task scores are explicit hypothetical structured inputs. The task score is not inferred from text or treated as an empirical outcome. This module implements one task-specific policy comparison, not an NLP detector, diagnosis, or population model. Strength is an uncalibrated intervention setting, not a human prevalence estimate or confidence. The cue priority may be irrelevant or misleading in other tasks; equal-weight aggregation is also only a stipulated reference, not a perfect-rationality benchmark. No empirical validity, effect size, or general benefit is claimed.
